# 발표 노트 — 전예진 상품 영역

> 캡처는 2026-10-11 `feature/yejin`(`8e7a01c`) 기준의 1차 구현 화면입니다. 상품 보틀 이미지는 최종 이미지가 아니며, 상품 6종을 기준으로 합니다.

## 1. 캡처별 설명

| 순서 | 파일 | 보여주는 기능 | 설명 |
|---|---|---|---|
| 1 | `desktop-products.png` | 상품 목록 | 공통 상품 데이터 하나로 카드를 그립니다. 필요 포인트는 원이 아니라 P로 표시하고, 향 계열과 용량을 함께 보여 줍니다. |
| 2 | `desktop-filtered-products.png` | 검색·필터·정렬 조합 | `wood` 검색 + Woody 필터 + 포인트 높은 순을 함께 적용한 결과입니다. 적용 중인 조건을 칩으로 보여 주고, 칩을 하나씩 지우거나 '조건 초기화'로 한 번에 되돌릴 수 있습니다. |
| 3 | `desktop-product-detail.png` | 상품 상세 | 향 이야기, TOP·HEART·BASE 노트, 제품 정보를 한 화면에 정리했습니다. 수량을 2로 바꾸면 필요 포인트가 92,000P로 바로 계산됩니다. |

## 2. 1분 발표 대본

> 저는 AURA에서 상품 영역을 맡았습니다. 상품 데이터와 이미지 연결, 목록·검색·필터·정렬, 상품 상세, Quick View와 관련 상품까지가 제 담당입니다.
>
> 먼저 여러 화면에 흩어져 있던 상품 정보를 하나의 데이터로 모았습니다. 그래서 목록, 상세, 미리보기, 관련 상품이 같은 이름과 포인트, 같은 이미지를 보여 줍니다.
>
> 컬렉션에서는 상품명, 향 노트, 향 계열을 한글과 영문으로 검색할 수 있고, 계열 필터와 포인트 정렬을 함께 쓸 수 있습니다. 필터는 주소에 남기 때문에 홈의 향 계열 링크로 들어와도 같은 결과가 나옵니다.
>
> 상세에서는 수량을 바꾸면 필요 포인트가 바로 계산되고, 포인트가 부족해도 장바구니에는 먼저 담을 수 있게 했습니다. 관련 상품은 같은 향 계열을 먼저 보여 줍니다.
>
> Quick View는 키보드만으로도 열고 닫을 수 있도록 포커스 이동을 신경 썼습니다. 마지막으로 375, 768, 1440픽셀 화면과 이미지가 실패한 상황까지 점검했습니다.

(약 1분, 380자 내외)

## 3. 문제 해결 사례 — 필터 호버

- **발견 (전예진 직접 확인)**: 상품 목록의 향 계열 필터에 마우스를 올리면 손가락 커서만 바뀌고 색·배경·테두리는 그대로였습니다. 클릭 기능과 키보드 포커스 표시는 정상이었습니다.
- **원인**: 필터 버튼 스타일에 기본 상태와 선택 상태만 있고 호버 상태가 없었습니다.
- **해결 (PR #8)**
  - 선택되지 않은 버튼에만 호버 스타일을 추가했습니다. 배경은 사이트에서 이미 쓰는 아이보리 `#ece9e1`, 테두리는 반투명 차콜입니다.
  - 선택된 버튼(`.is-active`)은 제외해서 검은 배경이 유지됩니다.
  - 키보드 포커스 표시(2px 앰버 테두리)는 `outline` 속성이라 호버 스타일과 겹치지 않습니다. 기존 규칙도 바꾸지 않았습니다.
  - `(hover:hover)` 조건 안에 넣어 터치 화면에서 탭한 뒤 색이 남지 않게 했습니다.
  - 움직임 줄이기 설정에서는 전환 효과를 끕니다.
  - 적용 범위를 `/products`의 필터 영역(`.shop-controls .filter-tabs`)으로 한정했습니다.
- **검증 (2026-10-11 통합 검수)**: 호버 시 배경·테두리 변화, 마우스를 치우면 복귀, 선택된 필터 유지, Tab 포커스 표시, Enter 선택 모두 PASS. 터치 기기에서는 아직 확인하지 않았습니다.

## 6. 다른 담당 영역 (발표 시 구분)

아래 기능은 상품 화면과 연결되지만 전예진의 구현이 아닙니다.
- **장바구니 화면, '장바구니에 담았어요' 대화상자, 포인트 교환·차감, 카드 번호 기반 회원가입·가입 혜택·카드별 적립 정책 (PR #7)**: 정다라
- **회원가입·로그인 화면, 헤더·푸터, 홈**: 고나경
- **카드 페이지·카드 데이터, 마이페이지, MY AURA Atelier (PR #6 등)**: 양성용

상품 영역의 역할은 상세에서 선택한 상품과 수량을 공통 장바구니 기능(`addToCart`)에 넘기는 데까지입니다. 로그인 안내는 상세로 돌아오는 링크(`?next=`)를 제공하는 데까지입니다.
