# AURA UI/UX 업데이트 — 조향 경험 중심

> 보관 기록입니다. 구현·경로·명령·검증 결과는 작성 당시 기준입니다. 현재 개발 방법은 [문서 목록](../README.md)에서 확인하세요.

## 적용 내용

- 조향 작업 화면을 PC 3열 / 태블릿 2열 / 모바일 비커 요약·향료 탐색·하단 CTA로 재구성.
- 작업 중 Footer를 숨기고 향료 목록과 조합 목록 내부에서만 스크롤.
- 모바일 내가 담은 향은 모달에서 횟수·비중·삭제 조절.
- 첫 번째 레퍼런스의 카드 색·선택 체크·칩·원형 버튼과 두 개의 카운터 복원. 진행 바의 구간·원형 진행률·단계 도트 구현.
- 투입 방울과 파동, 액체 높이·색 변경, 혼합 드래그·방향키·버튼 조작, 조작 중 액체 모션, 완료 후 디지털 시향 연출.
- 혼합·시향은 같은 모달의 단계로 표시. 포커스 제한·Escape 닫기·이전 조작부로 포커스 복귀. 선택은 닫아도 유지.
- PC 흔들기 버튼 숨김. 터치 모바일·센서·안전한 연결 환경에서만 표시, 지원되지 않으면 버튼/드래그 사용.
- 혼합·시향 중 이미지와 텍스트 선택 방지. 원본 이미지 dragging 방지.
- 결과의 보틀·이름·라벨·재료 펼쳐보기·저장/복사·다시 수정 행동 정리.
- 실제 checkbox/radio 의미를 유지한 디자인, 커스텀 combobox/listbox, 키보드 조작·선택·닫기.
- 로그인/회원가입/문의의 브라우저 기본 오류 팝업 대신 화면 오류 안내 및 오류 필드 focus.
- NAV 64px/56px, Chevron 제거, hover/키보드 focus/터치로 컬렉션 메뉴 탐색.
- 홈의 Hero·가입 배너·이미지·섹션 여백 축소. 모바일 상품 상세의 수량·장바구니 CTA 하단 고정.

## 화면 검사

높이 844px에서 너비 1440/1024/768/390/375px.
총 50개 화면·상태: 조향 선택/혼합/시향/결과, 홈/목록/Gift Set/로그인/회원가입/입점 문의.
가로 넘침·깨진 이미지·12px 미만 main UI 텍스트·브라우저 JS/React 오류: 0건.

조향 선택 화면 높이 844px, CTA가 모든 너비에서 화면 내에 존재. 390px에서 향 섞기 위치는 top 786px / bottom 834px. 향료 목록 내부의 스크롤은 필요하지만 조합·CTA를 찾기 위한 페이지 전체 스크롤은 제거했습니다.

홈 높이: PC 1440px 약 3840px, 모바일 390px 약 3769px. 이전 측정치 4528/4304px에서 줄였으며, 이미지 로딩과 표시 상태에 따라 조금 달라질 수 있습니다.

## 에셋과 운영 범위

public/assets/reference에 레퍼런스 색 보존 SVG 56개와 컬렉션 합성 SVG 3개 포함. 향료 13종 중 현재 후보와 대응되는 항목, 도구·결과 보틀, 컬렉션 등에 연결했습니다. 원본에 없는 향료 후보는 기존 벡터를 유지합니다. 픽셀 기반 SVG의 확대 한계·투명 외곽 차이는 이전 안내와 같습니다. 실시간 비커는 액체를 조작하기 위한 독립 벡터 레이어입니다.

서버 인증·실주문·PG·문의 접수 서버는 기존과 같이 미연동입니다. 실제 iPhone 센서와 VoiceOver는 이 환경에서 검증하지 않았습니다. PC Chrome 기반 키보드·드래그·버튼 대체 조작을 검사했습니다.

Windows에서는 START_HERE_KO.md의 자동 백업 적용 명령을 사용하세요. 사용자 PC의 push하지 않은 변경은 자동 백업되지만 이 소스에 사전 병합되어 있지는 않습니다. Git push는 실행하지 않습니다.
