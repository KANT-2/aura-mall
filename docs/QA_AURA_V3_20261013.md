# AURA V3 전체 디자인 소스 — 적용 안내

**2026-10-13 · Warm Editorial × Dark Atelier**

이 ZIP은 실행 가능한 Next.js 프로젝트의 전체 소스와 2D 에셋을 포함합니다. Codex 프롬프트가 아닙니다.

## Windows에서 적용

1. 기존 개발 서버를 `Ctrl+C`로 종료합니다.
2. ZIP을 `C:\dev\aura-mall` **바깥**의 폴더에 압축 해제합니다.
3. 압축 해제된 `aura-mall` 폴더의 PowerShell에서 실행하세요.

```powershell
python .\APPLY_TO_LOCAL.py --target "C:\dev\aura-mall" --apply
cd C:\dev\aura-mall
npm ci
npm run build
npm run dev
```

스크립트는 기존 교체 대상 폴더를 타임스탬프 백업에 먼저 복사합니다. `.git`, 루트 `.env*`, `node_modules`는 유지됩니다. **기존 미커밋 코드를 자동 병합하지 않습니다.** 필요하면 먼저 `git status`를 확인하세요. Git push는 수행하지 않았습니다.

## 포함한 실제 수정

- 홈: 오프화이트와 웜 소재의 대비, 짙은 코코아 프로모션 배너, 새로운 쿠폰 그래픽, 입점/푸터 대비 강화, 컬렉션 플레이트 디자인.
- 전체 커머스: 컬렉션/검색/상세/장바구니/회원/입점/마이페이지 색과 섹션 경계 개선. **기존 제품 사진은 미확정이므로 보존**.
- 향료: 24개 420×420 투명 WebP로 UI 적용. 원본 추적 SVG를 직접 불러오지 않음. 자산별 출처는 `public/assets/botanical-manifest.json`.
- SVG: 59개 실제 벡터 도구/라벨/비커/컬렉션 에셋 유지. 병·쿠폰·페이퍼 태그는 신규 벡터 수정. 2D 소재와 인터랙션 UI는 별도 관리.
- Atelier: 원형 드래그/회전 안내/분사 파티클/`+10%` 조작 제거 → `향 섞기` 클릭 → 약 2.4초 블렌딩 → Floating Notes → 병과 라벨에 이름 붙이기 → 저장.
- 결과와 마이페이지: 동일 병/라벨 디자인 언어 연결, 긴 레시피 펼치기, 표시 비중 합계 100% 정합성 개선.
