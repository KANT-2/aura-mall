# 2026.10.12 프로젝트 기획 개편안

**회의 주제:** AURA 서비스 방향 재정의, 상품·Gift Set·Personal Atelier 구조 확정, 역할 분담 및 최종 개발 방향 정리

**팀 구성:** 고나경·전예진·양성용·정다라

## 1. 서비스 방향

- AURA는 향을 발견하고, 프래그런스 제품을 탐색·구매하며, 직접 향을 조합해 나만의 향수를 만들 수 있는 **프래그런스 커머스 · 퍼스널 향수 아틀리에 서비스**로 구성한다.
- 브랜드 핵심 메시지는 **From Scent to Identity.**로 정의한다.
- 사용자는 복잡한 향수 분류 대신 **FRESH · SOFT · WARM** 세 가지 시그니처 컬렉션을 중심으로 자신의 취향에 맞는 향을 탐색한다.
- 일반 완제품 탐색과 구매뿐 아니라 **Gift Set 구성**, **AURA PERSONAL ATELIER**를 통해 사용자가 직접 참여하는 경험을 제공한다.
- 전체 서비스 경험은 **Discover → Explore → Create → Preserve → Purchase** 흐름으로 연결한다.
- 커머스 화면은 고급 제품 목업 중심으로 구성하고, 조향·브랜딩 영역은 Neo-Flat 기반 2D 일러스트와 인터랙션을 활용한다.
- Desktop / Mobile 환경을 모두 고려한 반응형 웹으로 구성한다.

## 2. 상품·컬렉션 구성

상품은 **FRESH / SOFT / WARM 3개 컬렉션**으로 구성한다.

각 컬렉션은 동일한 10개의 상품 유형을 제공하며,  
**3 Collections × 10 Product Types = 총 30개 기본 상품**으로 구성한다.

| 제품 유형 | FRESH | SOFT | WARM |
| --- | --- | --- | --- |
| Hand Cream | Fresh Hand Cream | Soft Hand Cream | Warm Hand Cream |
| Hand Wash | Fresh Hand Wash | Soft Hand Wash | Warm Hand Wash |
| Body Lotion | Fresh Body Lotion | Soft Body Lotion | Warm Body Lotion |
| Eau de Parfum | Fresh Eau de Parfum | Soft Eau de Parfum | Warm Eau de Parfum |
| Body Wash | Fresh Body Wash | Soft Body Wash | Warm Body Wash |
| Perfume Oil | Fresh Perfume Oil | Soft Perfume Oil | Warm Perfume Oil |
| Diffuser | Fresh Diffuser | Soft Diffuser | Warm Diffuser |
| Candle | Fresh Candle | Soft Candle | Warm Candle |
| Hair Mist | Fresh Hair Mist | Soft Hair Mist | Warm Hair Mist |
| Gift Set | Fresh Gift Set | Soft Gift Set | Warm Gift Set |

### 컬렉션별 콘셉트

| 컬렉션 | 콘셉트 | 주요 키워드 |
| --- | --- | --- |
| **FRESH** | 맑고 산뜻한 시트러스·그린 계열 | Clean / Citrus / Green / Refreshing |
| **SOFT** | 부드럽고 편안한 플로럴·머스크 계열 | Gentle / Floral / Soft / Comforting |
| **WARM** | 깊고 따뜻한 우디·앰버 계열 | Woody / Amber / Warm / Deep |

각 상품은 다음 정보를 기준으로 구성한다.

- 상품 ID

- 상품명
- 카테고리
- 가격
- 대표 이미지
- 상세 이미지

- 용량

- 필요 시 추천 또는 큐레이션 정보

상품 판매 이미지는 AURA 패키징을 표현한 고품질 제품 목업을 사용한다.

## 3. Gift Set 구성 정책

Gift Set은 미리 정해진 상품 묶음이 아니라,  
사용자가 같은 컬렉션 안에서 원하는 상품을 직접 선택하는 **구성형 선물 세트**로 제공한다.

### Gift Set 종류

- Fresh Gift Set
- Soft Gift Set
- Warm Gift Set

### 구성 규칙

- 해당 Gift Set과 같은 컬렉션의 일반 상품 9종 중 선택한다.
- **서로 다른 상품을 정확히 3개 선택**해야 한다.
- 다른 컬렉션 상품은 함께 선택할 수 없다.
- Gift Set 자체를 Gift Set 안에 포함할 수 없다.
- 3개 상품이 선택되기 전에는 장바구니 담기 버튼을 비활성화한다.
- 선택 상태는 `0/3 → 1/3 → 2/3 → 3/3` 형태로 명확하게 보여준다.
- 선택 완료 후 상품 이미지와 상품명을 요약 영역에 표시한다.
- 장바구니와 주문 상세에서도 Gift Set의 선택 상품 구성을 확인할 수 있도록 한다.

예시:

`Fresh Gift Set = Fresh Eau de Parfum + Fresh Hand Cream + Fresh Candle`

## 4. 장바구니·주문·배송 정책

### 장바구니

사용자는 일반 상품과 Gift Set을 장바구니에 담을 수 있다.

장바구니에는 다음 정보를 표시한다.

- 상품 이미지
- 상품명
- 컬렉션
- 상품 옵션 또는 Gift Set 구성
- 수량
- 상품 가격
- 수량 변경
- 상품 삭제
- 총 상품금액
- 배송비
- 예상 결제금액

장바구니 상태에서는 상품 수량 변경·삭제·합계 계산의 기준을 통일하여 화면 간 데이터가 일관되게 유지되도록 한다.

### 주문

기본 흐름은 다음과 같이 구성한다.

`상품 탐색 → 상품 상세 → 장바구니 → 주문 정보 확인 → 주문 흐름`

실제 PG 결제 기능과 주문 서버 연동은 별도 개발 범위로 구분한다.

### 배송

- 기본 배송비는 **3,000원**을 기준으로 한다.
- 신규 회원에게는 배송비 쿠폰을 제공하는 방향으로 구성한다.
- Custom 향수는 일반 상품과 제작·출고 일정이 다를 수 있으므로 별도 정책이 필요하다.

## 6. AURA PERSONAL ATELIER

AURA PERSONAL ATELIER는 사용자가 직접 향료를 선택하고 조합해 자신만의 향수를 만드는 인터랙티브 서비스다.

초기 Custom 상품 범위는 **향수**로 제한한다.

### 기본 사용자 흐름

`Atelier 진입`
→ `추천으로 시작 / 직접 만들기`
→ `향의 분위기 선택`
→ `추천 재료 확인`
→ `Top / Middle / Base 향료 선택`
→ `비커에 투입`
→ `비중 확인`
→ `향 섞기`
→ `디지털 시향`
→ `결과 확인`
→ `향 이름·라벨 설정`
→ `내 향 저장`

### 향료 구성

향료는 다음 3개 영역으로 구분한다.

- Top Note
- Middle Note
- Base Note

초기 기획 기준으로 각 노트별 8종, 총 24종의 향료 후보를 구성한다.

### 선택 방식

- 한 노트에서 여러 향료를 선택할 수 있다.
- 같은 향료를 반복해서 선택할 수 있다.
- 향료를 선택할 때마다 투입 횟수가 증가한다.
- 전체 선택 횟수 대비 각 향료의 비중을 계산해 보여준다.
- 선택한 향료는 노트 탭을 이동해도 유지한다.
- 감소·삭제·전체 비우기 기능을 제공한다.

### 비커 인터랙션

향료를 선택하면:

- 향료 방울이 비커로 떨어지고
- 선택 횟수가 증가하며
- 향료 비중이 변경되고
- 액체 높이와 색상이 시각적으로 변화한다.

### 블렌딩

Desktop:
- 마우스 또는 트랙패드의 원형 드래그 방식

Mobile:
- 지원 환경에서는 흔들기 인터랙션
- 미지원 환경에서는 터치 방식 대체

혼합 진행률은 0~100%로 표현한다.

### 결과

완성 후 다음 정보를 보여준다.

- 완성 향수 이미지
- 향 이름
- 라벨
- 선택한 향료
- 향료별 선택 횟수
- 향료 비중
- 블렌딩 색상
- 내 향 저장

## 7. 개발 방향

- **Next.js App Router + TypeScript + Tailwind CSS** 기반으로 개발한다.
- 공통 UI는 재사용 가능한 컴포넌트 단위로 분리한다.
- 홈, 상품 목록, 상품 상세 등 발제 필수 화면을 우선 안정화한다.
- FRESH / SOFT / WARM 상품 데이터를 기준으로 상품 탐색 구조를 구성한다.
- 상품 목록은 데이터 기반 반복 렌더링 방식으로 구성한다.
- 상품 상세 화면은 상품 ID를 기반으로 연결한다.
- Gift Set의 상품 3개 선택 상태를 명확하게 관리한다.
- 장바구니의 수량·삭제·합계 계산 상태를 일관되게 관리한다.
- PERSONAL ATELIER의 향료 선택·비중·비커·블렌딩 흐름을 단계적으로 연결한다.
- Desktop / Tablet / Mobile 환경에서 레이아웃을 검수한다.
- 한글 줄바꿈, 이미지 잘림, 버튼 접근성, UI 겹침 등을 통합 QA에서 확인한다.
- Git / GitHub 브랜치와 PR을 통해 팀원별 작업을 통합한다.
- 최종 빌드, README, 화면 캡처, 컴포넌트 구조도, 발표·시연 자료를 준비한다.
