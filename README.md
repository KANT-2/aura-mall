# AURA 포인트몰 — 프로젝트 기획 및 구현 현황

**정책·구현 현황 갱신:** 2026.10.10, feature/dara 작업 기준. 팀 전체 반영은 PR 검토 후 진행한다.

**회의 주제:** 서비스 콘셉트, 카드 혜택·교환 정책, 역할 분담 및 개발 방향 정리

**팀 구성:** 고나경·전예진·양성용·정다라

## 1. 서비스 방향

- 가상의 카드사 포인트몰에 향 제품을 접목한 서비스를 제작한다.
- 카드 브랜드는 **아우라 카드(Aura Card)**이며, **Dew·Velvet·Amber** 3종으로 구성한다.
- 고객은 카드 **1종을 보유**하며, 카드 종류와 관계없이 전체 상품을 교환할 수 있다.
- 카드별 차이는 **가입 보너스·적립률**으로 표현한다.
- 화면과 문서의 용어는 **장바구니·교환·교환 확인·교환 완료·교환 내역**으로 통일한다.
- 상품 가격, 배송비, 잔액, 적립금의 단위는 모두 **P**로 표시한다.

초기 기획은 **총 12개**, 컬렉션별 **4개**, 상품당 재고 **15개**다. 아래 목록은 초기 기획이며, 현재 상품 UI는 `data/products.ts`의 **6종 Mock Data**를 사용한다. 최종 상품 수와 재고 관리 구현 범위는 팀 확인이 필요하다.

| 컬렉션 | 콘셉트 | 상품 및 가격 |
| --- | --- | --- |
| **Dew — Light & Fresh** | 맑고 가벼운 데일리 향 | Fresh Berry Perfume Mist 24,000P / Soft Cotton Hand Cream 12,000P / Citrus Hand Wash 15,000P / Milk & Berry Body Lotion 22,000P |
| **Velvet — Soft & Deep** | 부드럽고 깊은 프리미엄 향 | Fig & Musk Eau de Parfum 46,000P / Blue Tea Hand Balm 18,000P / Hinoki Body Wash 27,000P / White Musk Body Lotion 32,000P |
| **Amber — Warm & Rare** | 따뜻하고 깊은 시그니처 향 | Amber Woods Perfume Oil 68,000P / Black Tea & Leather Candle 52,000P / Oud & Rose Diffuser 74,000P / Signature Scent Gift Set 98,000P |

메인에서 컬렉션을 선택하면 해당 상품 4개를 확대하거나 테두리로 강조한다. 다른 컬렉션 상품도 계속 탐색할 수 있도록 구성한다.

**컬렉션 둘러보기와 실제 보유 카드 변경은 별도 기능으로 구분한다.**

## 3. 카드별 혜택

| 카드 | 포인트몰 가입 보너스 | 상품 교환 적립률 | 배송비 |
| --- | --- | --- | --- |
| Dew | 10,000P | 1% | 무료배송 |
| Velvet | 30,000P | 3% | 무료배송 |
| Amber | 50,000P | 5% | 무료배송 |
- 가입 보너스는 **포인트몰 최초 가입 시 1회** 지급한다.
- 가입 후 카드 변경은 미구현이다. 향후 제공 시 가입 보너스를 추가 지급하거나 기존 지급분을 회수하지 않는 정책을 따른다.
- 향후 카드 변경 시 포인트 잔액과 장바구니를 유지하도록 한다.
- 신규 교환 내역에는 당시 카드·적립률·금액을 저장한다. 향후 카드 변경 혜택은 변경 이후 교환에 적용한다.

## 4. 교환·장바구니 정책

- 전 상품 무료배송이며 **총 사용 포인트 = 상품 합계**다.
- 적립 포인트는 상품 합계 × 카드 적립률의 **소수점 버림**으로 계산한다.
- 교환 전 상품 합계를 지불할 잔액이 필요하다. 이번 교환의 예상 적립금으로 부족분을 충당할 수 없다.
- 부족 포인트를 표시하고 교환을 차단한다. 적립금은 교환 완료 후 잔액에 반영하여 다음 교환부터 사용한다.
- 장바구니 담기 후 **계속 둘러보기 / 장바구니로 이동** 확인창을 제공한다. 장바구니 Drawer는 구현하지 않는다.
- 교환 확인창에서 상품·옵션·수량·사용 포인트·적립·최종 잔액을 확인하고 취소하거나 확정한다. 취소하면 잔액과 장바구니를 유지한다.
- 교환 완료 시 상품명·수량·사용 포인트·적립 포인트·교환 후 잔액을 표시하고 장바구니를 비운다.
- 포인트 내역은 교환과 해당 적립을 한 묶음으로 표시한다. 날짜를 맨 위에 표시하고 최신 교환부터 정렬하며, 시간은 표시하지 않는다.
- 일반 상품은 같은 상품을 다시 담으면 수량을 합산한다. 수량은 최소 1개이며, 변경·삭제 시 합계와 헤더의 총수량을 갱신한다.
- 커스텀 상품은 **같은 향료 조합 + 같은 제품 종류**이면 수량을 합산한다. 향료 선택 순서는 무관하며, 가격이 다른 항목은 합계를 보존하기 위해 별도로 유지한다.
- MY AURA에서는 TOP·HEART·BASE마다 향료를 **각각 하나씩** 선택한다. 다른 향료 조합이나 제품 종류는 별도 상품이다.
- 현재 회원·포인트·장바구니는 브라우저 `localStorage` 기반이다. PostgreSQL·서버 검증·재고 트랜잭션은 아직 연결하지 않았다.
- 같은 화면에서 확정 버튼의 반복 실행을 막는 장치를 적용했다. 여러 탭·동시 요청에 대한 서버 수준 보장은 남은 검수·구현 범위다.
- 장바구니는 공용 `aura_cart_v1`에 저장하며, 로그아웃하면 비운다. 이는 확정된 정책이다. 회원별 장바구니 보관 기능은 구현하지 않는다.

## 5. 회원·포인트 운영

- 회원가입 입력: 이름·이메일·비밀번호·비밀번호 확인·**AURA 테스트 카드 번호**.
- 카드 번호는 **16자리**, 화면에서는 `4자리 4자리 4자리 4자리`로 자동 표시한다.
- 첫 숫자 **0·1·2·3 → Dew / 4·5·6 → Velvet / 7·8·9 → Amber**로 판별한다. 카드 선택 목록 대신 판별된 카드와 혜택을 안내한다.
- 번호 전체는 저장하지 않고 카드 종류만 회원 정보에 저장한다. 실제 카드사 조회·실적 연동·CVC·유효기간 입력은 구현하지 않는다.
- 카드별 가입 보너스를 신규 가입 시 한 번 지급하고 가입 내역을 기록한다. 재로그인 시 다시 지급하지 않는다.
- 비밀번호는 현재 최소 8자로 검증하고 PBKDF2 해시와 salt로 저장한다. 영문·숫자·특수문자 조합 검증은 초기 기획으로, 현재 구현에는 없다.
- 비회원도 상품 탐색과 장바구니 담기가 가능하며, 교환·마이페이지는 로그인 후 이용한다.
- 기존 카드 정보가 없는 다라 계정은 Amber, hayoung 계정은 Velvet으로 연결하고 기존 잔액·내역을 유지한다. 다른 기존 계정의 기본값은 Velvet이다. 기존 계정에는 가입 보너스를 추가 지급하지 않는다.
- 가입 후 카드 변경 UI는 아직 구현하지 않았다. 컬렉션 탐색은 보유 카드 등급을 변경하지 않는다.

**테스트 계정 운영**

- 신규 계정으로 카드별 가입 보너스·부족 안내를, 테스트 계정으로 정상 교환을 시연한다.

## 6. 개발 방향

- 현재 **Next.js App Router·TypeScript·Tailwind CSS**와 브라우저 저장을 사용한다. **PostgreSQL은 초기 계획이며 미연결**이다.
- 공통 컴포넌트를 분리하고 반응형 화면을 기본 목표로 진행한다.
- 상품 탐색 화면을 먼저 완성하고 회원·장바구니·교환 기능을 연결한다.
- 관리자 화면은 핵심 기능 완성 후 여력을 보고 추가한다.
- 실제 PG 결제 모듈은 구현하지 않는다.
- 최종 빌드 확인, README, 화면 캡처, 발표·시연 자료를 준비한다.

### 최근 화면·UX 변경

- 모바일·태블릿 헤더는 메뉴 / 중앙 AURA 로고 / 수량 배지가 있는 장바구니로 구성한다. 회원명·마이페이지·포인트 지갑·로그아웃 및 비회원 로그인·가입은 메뉴 안에 표시한다.
- 모바일 커스텀 장바구니의 TOP·HEART·BASE를 상품명 아래 오른쪽 3열로 배치한다.
- 태블릿 CURRENT RECIPE를 향료 라이브러리 아래로 배치한다.
- 컬렉션의 ‘향 검색’ 줄바꿈을 막고 ‘정렬’과 선택값 사이 간격을 추가한다.
- 향료 안내를 ‘TOP·HEART·BASE에서 향료를 하나씩 선택해 주세요.’로 수정하고 진행률 제목을 ‘향료 선택’으로 명확히 한다.
- FINAL PRODUCT 아래에 ‘선택한 구성 확인하기’를 배치한다. 구성 확인 후 장바구니 담기 흐름은 유지한다.
